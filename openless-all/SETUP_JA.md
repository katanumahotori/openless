# OpenLess（片沼版フォーク）セットアップガイド

このガイドは **katanumahotori/openless**（片沼ほとりが日本語ユーザー向けに改造したフォーク版）を、初めて使う人向けに書いています。

OpenLess は **音声入力 → AI 整文 → カーソル位置に挿入** を行う Windows / Mac 向けのデスクトップアプリです。Whisper（音声認識）と LLM（整文）はクラウド API を呼び出すので、**ネット接続と無料の API キー** が必要です。

## このフォーク版で何が改造されているか

upstream（元の OpenLess）から以下を改造／追加：

- **日本語フォントを内蔵**：Noto Sans JP を同梱、UI が中華フォントにならない
- **辞書を Whisper にも渡す**：固有名詞（梁山泊・なにわづ等）の漢字を STT 段階で正しく書き起こす
- **全モード共通プロンプト**：句読点ルール等を全スタイルに常時適用できるテキストエリア
- **カスタム整文モード**：4種類の標準モードに加えて、自分でプロンプトを書いたモードを足せる
- **アプリ別自動切替**：使ってるアプリで使う整文モードを自動切替
- **翻訳機能の明示的なON/OFF**：誤発火防止
- **TSF（Windows IME）回避**：ATOK 干渉問題の解消
- **漢字押し出し対策**：ATOK・Microsoft IME での文字順序エラー解消

## 必要なもの

- Windows 10/11（64bit） or macOS 12 以降
- インターネット接続
- 無料の **Groq API キー**（クレジットカード登録不要）

## 1. ダウンロード + インストール

### Windows

1. [Releases ページ](https://github.com/katanumahotori/openless/releases) から最新の `OpenLess_x.x.x_x64-setup.exe`（NSIS 版）または `OpenLess_x.x.x_x64_en-US.msi`（MSI 版）をダウンロード
2. ダブルクリックで起動
3. Windows SmartScreen が **「PC が保護されました（不明な発行元）」** と出たら：
   - 「**詳細情報**」をクリック
   - 「**実行**」をクリック
   - 個人開発のフリーソフトのため証明書を取得していません。コードは GitHub で公開済みなので、不安なら一度ソースを見てから判断してください
4. インストーラの指示に従ってインストール
5. スタートメニューに「OpenLess」が追加される

### macOS

1. [Releases ページ](https://github.com/katanumahotori/openless/releases) から `OpenLess_x.x.x_aarch64.dmg`（M1/M2/M3）または `OpenLess_x.x.x_x64.dmg`（Intel）をダウンロード
2. dmg を開く → アプリを Applications にドラッグ
3. 初回起動時に **「開発元を確認できないため開けません」** と出たら：
   - システム設定 → プライバシーとセキュリティ → 「**このまま開く**」をクリック

## 2. Groq API キーを取得（無料、クレカ不要）

1. https://console.groq.com にアクセス
2. **Sign Up**（GitHub または Google アカウントでログイン可。メアド登録もOK）
3. **クレジットカード登録は不要**。プロンプトが出ても無視して進んでOK
4. ログイン後、左メニューの **API Keys** へ
5. **Create API Key** ボタン → 名前は任意（"OpenLess" 等）
6. 表示された **`gsk_...` で始まるキーをコピー**（**この画面を閉じると二度と表示できないので注意**）

無料枠：
- Whisper（音声認識）：1日 8時間ぶんの音声まで
- LLM（整文）：選んだモデル次第で 1日 100K〜500K トークンまで（普通の使い方なら超えない）

## 3. OpenLess の設定

OpenLess を起動すると初期設定画面が出ます。

### 3-1. ASR（音声認識）プロバイダ設定

1. 設定画面で **ASR プロバイダ** → **カスタム** を選択
2. **API キー**：先ほどコピーした `gsk_...` のキーを貼り付け
3. **エンドポイント**：`https://api.groq.com/openai/v1`
4. **モデル**：`whisper-large-v3-turbo`

### 3-2. LLM（整文）プロバイダ設定

1. **LLM プロバイダ** → **カスタム** を選択
2. **API キー**：同じ `gsk_...` のキー（Whisper と LLM で同じキーが使えます）
3. **エンドポイント**：`https://api.groq.com/openai/v1`
4. **モデル**：以下のいずれか（推奨順）：
   - **`openai/gpt-oss-120b`** — 速度・賢さ・無料枠（200K/日）のバランス最強。**初心者にはこれを推奨**
   - **`qwen/qwen3-32b`** — 日本語特化、無料枠 500K/日 と最大。ただし thinking モードのぶん少し遅い
   - **`llama-3.3-70b-versatile`** — Meta 製、安定。無料枠 100K/日 とやや小さい
   - **`llama-3.1-8b-instant`** — 超高速・無料枠 500K/日 だが整形精度は明確に劣る

### 3-3. 動作確認

設定画面の **「接続テスト」** ボタンで両方とも緑（成功）になればOK。

## 4. 推奨設定（日本語ユーザー向け）

### 4-1. 全モード共通の指示（タイポグラフィ規約）

設定 → **スタイル** → **全モード共通の指示** に以下をコピペ推奨：

```
タイポグラフィ規約：
- 感嘆符 ！と疑問符 ？は、ユーザーが明確に感嘆／疑問の語気で発音した時のみ使う。普通の平叙文（「〜です」「〜ます」「〜と思います」等）には絶対に追加しない
- 上記で ！か ？を出力した場合のみ、その直後に全角スペース「　」を1つ入れる
- 句読点は半角の , . ではなく全角の 、 。を使う
```

これで「**正しい全角句読点**」「**！と？の後の全角スペース**」が常時適用されます。

### 4-2. 語彙（辞書）登録

固有名詞（人名・社名・専門用語）を **語彙** ページに登録すると、Whisper の段階で正しい漢字に変換されやすくなります。

- 「**プリセットの外の自由入力欄**」に直接入力する形が一番効きます
- 例：「梁山泊」「片沼ほとり」など

### 4-3. ホットキー設定

デフォルトの録音開始キー（**右 Shift キー** など）が他のアプリと衝突する場合は、設定 → **録音** で変更できます。

## 5. 使い方

1. 任意のアプリ（メモ帳、ブラウザ、メーラー、Word 等）でカーソルを文字入力可能な場所に置く
2. ホットキーを押す → カプセルが画面端に出現、録音開始
3. 喋る
4. もう一度ホットキーを押す → 録音終了
5. AI が整文 → カーソル位置に **自動でテキスト挿入**

## 6. 整文スタイルの切替

設定 → **スタイル** に4つの標準モード：

- **原文（raw）**：句読点だけ補う、整形なし
- **軽い整文（light）**：「えーと」を除去、自然な文章へ
- **明確な構造（structured）**：複数トピックを箇条書きに
- **正式な表現（formal）**：メール／業務文体に整形

カードの ◯ を押してデフォルトを切替。「アプリ別自動切替」を設定すると Outlook で自動的に formal、Word で structured、等の運用が可能。

## 7. プライバシー

- **音声データ**：Groq に HTTPS で送信、Groq 側で文字起こし後すぐ破棄（保持されない）
- **整文テキスト**：同じく Groq に送信、整形結果が返る
- **ローカル保存場所**：
  - 設定：`%APPDATA%\OpenLess\preferences.json`
  - 履歴：`%APPDATA%\OpenLess\history.json`（最新 200 件）
  - 辞書：`%APPDATA%\OpenLess\dictionary.json`
- **API キー**：Windows Credential Manager（macOS は Keychain）に **暗号化保存**。preferences.json には平文で書かれない

## 9. トラブルシューティング

### 起動しない
- Windows: WebView2 ランタイムが必要。多くの Windows 11 には標準で入っているが、入っていない場合は [Microsoft 公式](https://developer.microsoft.com/microsoft-edge/webview2/) からダウンロード
- 設定が壊れた可能性 → `%APPDATA%\OpenLess\preferences.json` を退避してから起動するとデフォルトに戻る

### 文字が逆順・押し出される（Windows）
- このフォーク版では対策済みのはず。それでも起きたら Issue として katanumahotori/openless にお願いします

### 整文が外れる（raw のまま挿入される）
- LLM の無料枠を超過した可能性。**翌日 9 時（UTC 0時）に自動リセット**されるので、それまで待つ
- 頻発するなら、より無料枠の大きいモデルに切り替え（Qwen3-32B が 500K/日 で最大）

### 漢字が誤変換される（特に固有名詞）
- 語彙ページに登録（**プリセットの外の自由入力欄**にも追加するとなお良い）
- それでも直らない単語は、整文プロンプト（共通の指示）に「`量産泊` ではなく `梁山泊`」のように明示

### Mac で「開発元を確認できない」エラー
- システム設定 → プライバシーとセキュリティ → 「このまま開く」
- これでも開かない場合：ターミナルで `xattr -d com.apple.quarantine /Applications/OpenLess.app`

### 録音されない
- マイクのアクセス権限を OS 側で OpenLess に許可（Windows: 設定 → プライバシー → マイク。Mac: システム設定 → プライバシー → マイク）
- ホットキー競合の可能性 → 別のキーに変更してみる
